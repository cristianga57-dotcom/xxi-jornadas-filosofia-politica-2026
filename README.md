# XXI Jornadas Internacionales de Filosofía Política

Sitio web de las jornadas de la Universitat de Barcelona, 26 y 27 de noviembre de 2026.

Incluye el programa actualizado, las comunicaciones y resúmenes disponibles, las conferencias magistrales, las indicaciones para ponentes y la ubicación.

## Publicación

En **Settings → Pages**, seleccionar **Deploy from a branch**, rama **main**, carpeta **/ (root)** y guardar.

El sitio es estático y no requiere compilación. El programa descargable se encuentra en `assets/programa-completo.pdf`.
